## Project conventions

- Package manager: **pnpm** (never npm/yarn). Add deps with `pnpm add`.
- Lint + format: **Biome** (no ESLint/Prettier). Run `pnpm format` before committing; `pnpm lint` must pass.
- UI: Tailwind CSS v4 + **shadcn/ui** (Base UI primitives). Add components with `pnpm dlx shadcn@latest add <name>`; they land in `src/components/ui/` and may be edited. Use `cn()` from `@/lib/utils` to merge classes.
- Tests: **Vitest** + Testing Library for unit tests (`*.test.tsx` next to the code, `pnpm test`); **Playwright** for end-to-end tests in `e2e/` (`pnpm test:e2e`).
- Before finishing a change run: `pnpm lint && pnpm typecheck && pnpm test`.

## Todo data layer

- Domain code lives in `src/lib/todo/` (types, pure `todoReducer`, sorting, dates, effort helpers).
- Every change is a `TodoAction`; the same reducer updates the UI state (`TodoProvider` / `useTodos` in `store.tsx`) and is persisted through the `TodoRepository` interface (`repository.ts`).
- Two implementations, chosen on the server by `getStorageMode()` (`src/lib/storage-mode.ts`):
  - **database** (when `DATABASE_URL` is set): `ApiTodoRepository` sends actions to `/api/todo`, which applies them with `applyTodoActions` (`db-repository.ts`): load the user's rows, run `todoReducer`, write back changed rows, in one transaction. On first use it copies tasks from the browser's localStorage if the database is empty.
  - **local** (no `DATABASE_URL`: local dev, CI, e2e): `LocalStorageTodoRepository` (key `zaneta:todo:v1`), no login.

## Database and login

- Postgres (Neon on Vercel) via **Drizzle ORM** + `pg`. Schema in `src/db/` (`auth-schema.ts` is generated by the Better Auth CLI, `todo-schema.ts` is ours). Tables are plain rows, so `pg_dump` is a full export.
- After changing the schema run `pnpm db:generate` and commit the SQL in `drizzle/`. `pnpm build` applies pending migrations first (`scripts/migrate.mjs`, skipped without `DATABASE_URL`).
- Login: **Better Auth** with Google only (`src/lib/auth.ts`). Only e-mails in `ALLOWED_EMAILS` can sign in; it is checked on sign-in and on every request (`getCurrentUser`). Pages that show tasks call `requireTodoAccess()` inside `<Suspense>`.
- Env vars: see `.env.example`. Local database: put `DATABASE_URL` etc. in `.env.local`.
